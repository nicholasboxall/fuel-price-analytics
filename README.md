# fuel-price-analytics

I would like to include the file I used to do my analysis in this repository, however
even in a .csv format, it is still too large. 

You can recreate the file by creating a free account and accessing
https://opendata.transport.nsw.gov.au/dataset/fuelcheck.

There you can download a file containing data for every petrol
station in NSW every month for over 10 years. From there, you can combine them but unfortunately,
the columns are in slightly different arrangements with different headers, but the data is the same.

Alternatively, contact me at nicholasboxa03@gmail.com and I can provide you with a copy of the dataset.
